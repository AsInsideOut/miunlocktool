# **Xiaomi Unlock Tool**



## **About**

##### Xiaomi Unlock Tool is universal program for unlocking bootloader on your Xiaomi/Redmi/Poco phone that runs on HyperOS! All HyperOS versions work **EXCEPT** China (CNXM).

##### \----------***Supported platforms***----------

**Windows**



##### \----------***How to install (PC/Windows)***----------
###### 1\) Download new version from Releases page.
###### 2\) Unarchive the whole ZIP anywhere.
###### 3\) Open "Xiaomi Unlock Tool ." (. - version number).



#### \----------***How to install (PC/Linux/MacOS)***----------
###### 1\) Install any program that is able to run Python files.
###### 2\) Use the latest Python version.
###### 3\) Install the following modules:
###### customtkinter
###### packaging
###### ntplib
###### darkdetect
###### pytz
###### urllib3
###### icmplib
###### requests
###### pygame-ce


##### \----------***INSTRUCTIONS***----------
###### 1\) Read the Welcome text and click "Continue".
###### 2\) In the program itself, click "Instructions and Script settings".
###### 3\) Click "Getting Cookies" and choose your browser.
###### 4\) Follow the tutorial and get "new\_bbs\_token".
###### 5\) Close the instructions window and go to main program.
###### 6\) Insert your "new\_bbs\_token" in the field and click "Start application".
###### 7\) Wait for 23:58 in Beijing, the program synchronizes the time again.
###### 8\) Wait for 23:59.40, the program will start calculating ping.
###### 9\) In 23:59.58 the program sends the request (or spam them if spam is enabled in the settings).
###### 10\) In 00:01 (Beijing) you can try to bind your Account in developer settings.
###### That's it!



##### \----------***COMMON PROBLEMS AND FIXES***----------
###### "Couldn't add. Please go to Mi Community to apply for authorization"
###### Sadly, there isn't any fix for that. It's because Xiaomi has limited the devices per day that can be binded (1500 devices). It all depends on your ping and luck.

###### "System is being upgraded. Please try again later" - Most of the time its Redmi 13/Redmi Note 13 series glitch. You only need to wait for Xiaomi to fix this in the future updates
